The formalization constructs two maximally monotone operators on real `c₀`
that satisfy the interior-domain qualification while their sum is not
maximally monotone. The source README records proof coverage, checking
instructions, and Comparator verification. No arXiv identifier is available
at the time of this catalog entry.
