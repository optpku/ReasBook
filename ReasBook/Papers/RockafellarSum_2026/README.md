# Technical note: a counterexample to the Rockafellar sum conjecture on c₀

This is a catalog link folder on `main`; the complete Lean formalization is
kept on the `v4.32.0` version branch.

**[Open the source on `v4.32.0`](https://github.com/optpku/ReasBook/tree/v4.32.0/ReasBook/Papers/RockafellarSum_2026/)**

- **Authors:** Junyu Zhang, Jinbiao Chen, Zichen Wang, Benqi Liu, and Zaiwen Wen (2026)
- **Contributor:** Zichen Wang ([@imathwy](https://github.com/imathwy))
- **Original repository:** [rockafellar_sum](https://github.com/imathwy/rockafellar_sum)
- **License:** Apache License, Version 2.0

The formalization constructs two maximally monotone operators on real `c₀`
that satisfy the interior-domain qualification while their sum is not
maximally monotone. The source README records proof coverage, checking
instructions, and Comparator verification. No arXiv identifier is available
at the time of this catalog entry.
