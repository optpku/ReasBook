# Optimization Theory and Methods: Nonlinear Programming

[Lean source root](Book.lean)

Wenyu Sun and Ya-xiang Yuan, first edition (2006), Springer.

Lean 4 formalization covering unconstrained optimization, line-search and
trust-region methods, conjugate-gradient and quasi-Newton methods, and constrained
optimization topics across Chapters 1–14. A local compatibility layer adapts the
source snapshot to stable Lean and mathlib `v4.30.0`.
